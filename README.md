# 🔐 Secure Login JavaFX

A secure user authentication desktop application built using JavaFX.
This project implements a Sign Up and Login system with password hashing, input validation, and a Gmail-only registration policy to ensure secure user authentication.

The application demonstrates best practices in user authentication, data validation, and secure password storage in Java desktop applications.

## 🚀 Features

- 👤 User Sign Up (Registration)

- 🔑 Secure Login Authentication

- 🔒 Password hashing for secure storage

- 📧 Gmail-only registration policy

- ✔️ Input validation for user fields

- ⚠️ Error handling and validation messages

- 🖥️ Clean JavaFX UI

## 🛠️ Technologies Used

- Java

- JavaFX

- MySQL / Relational Database

- JDBC

- Password Hashing (e.g., BCrypt / SHA)

- IntelliJ IDEA / Eclipse

🔐 Security Features

- Password hashing before storing in the database

- Input validation to prevent invalid data

- Gmail-only email validation for registration

- Secure authentication process

##  🎯 Objectives

- Implementing secure authentication systems

- Building desktop applications with JavaFX

- Using password hashing for security

- Applying input validation and error handling
